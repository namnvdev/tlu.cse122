Array và object: tóm tắt sản phẩm

Mỗi object biểu diễn một sản phẩm; array lưu danh sách. filter, map và reduce tạo các góc nhìn từ cùng dữ liệu.

Mã nguồn

const products = [
  { name: "Sổ tay", price: 45_000, stock: 12 },
  { name: "Bút máy", price: 120_000, stock: 4 }
];
const affordable = products.filter(p => p.price <= limit);
const labels = affordable.map(({ name, price }) => ({ name, price }));
const total = labels.reduce((sum, item) => sum + item.price, 0);
