Promise chain và async/await

Mỗi tác vụ hoàn tất sau một timer. Chọn nhánh thành công hoặc thất bại để theo dõi chuỗi xử lý và dọn trạng thái.

Chạy thử

Chọn một cách chạy.

Quy ước kết quả

function getResult(shouldFail) {
  return new Promise((resolve, reject) => {
    setTimeout(() => {
      if (shouldFail) reject(new Error("Tác vụ thất bại"));
      else resolve("Dữ liệu đã sẵn sàng");
    }, 400);
  });
}
