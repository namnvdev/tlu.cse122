Fetch một resource kiểu REST

Demo GET tới JSON tĩnh trong cùng origin. Nút thứ hai yêu cầu resource không tồn tại để minh họa HTTP 404.

Request

GET ./products.json · Accept: application/json

Chưa gửi request.

Mã xử lý

const response = await fetch(url);
if (!response.ok) throw new Error(`HTTP ${response.status}`);
const data = await response.json();
render(data);
