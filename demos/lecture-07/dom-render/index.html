Tạo giao diện từ DOM nodes

JavaScript tạo từng element, gán văn bản bằng textContent và lắp node vào vùng chứa.

Mã JavaScript

const card = document.createElement("article");
card.className = "card";
const title = document.createElement("h3");
title.textContent = product.name;
card.append(title);
container.append(card);
