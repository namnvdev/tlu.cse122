Rule nào đang quyết định màu?

Bật/tắt class và rule cuối; so sánh specificity, source order và computed style.

Nội dung thử nghiệm trong preview

Các rule trong stylesheet

.notice { color: #0878f9; }
.preview.strong .notice { color: #b42336; }
#target { color: #6537a8; }
/* rule cuối; disabled ban đầu */
.notice { color: #167448; }

Chọn phần tử trong DevTools → Elements → Styles để nhận biết rule khớp và rule bị ghi đè; Computed hiển thị giá trị cuối.
