HTML RESPONSE → BROWSER UI

Trang Web đầu tiên

Browser nhận một tài liệu HTML, áp dụng CSS và hiển thị nội dung này.

Quan sát tài nguyên

Mở DevTools → Network, tải lại trang và tìm index.html cùng styles.css.

Mở Elements để xem cấu trúc DOM mà browser dựng từ HTML.

Chưa có tương tác

URL trên thanh địa chỉ dùng file:// khi mở trực tiếp. Dùng local HTTP server để quan sát request qua HTTP.
