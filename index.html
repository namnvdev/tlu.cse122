TỔNG QUAN HỌC PHẦN

Học từ nền tảng, tích hợp thành sản phẩm

Nội dung học phần

CSE122 cung cấp nền tảng khoa học và kỹ năng thực hành về phát triển ứng dụng Web phía máy khách. Sinh viên tìm hiểu cơ chế hoạt động của Web và mô hình client–server; xây dựng tài liệu HTML có ngữ nghĩa; thiết kế giao diện responsive, mobile-first và hỗ trợ khả năng tiếp cận bằng CSS, Flexbox, Grid và Bootstrap; lập trình tương tác với JavaScript, DOM và sự kiện; xử lý bất đồng bộ; tiêu thụ REST API bằng Fetch API.

Git/GitHub và Chrome DevTools được dùng để quản lý phiên bản, gỡ lỗi và triển khai. Học phần kết thúc bằng một dự án Frontend tích hợp, làm nền tảng cho học phần Phát triển ứng dụng Web nâng cao.

Mục tiêu & cách học

  • Hiểu cơ chế Web và công nghệ nền tảng phía client.
  • Xây giao diện có ngữ nghĩa, hỗ trợ khả năng tiếp cận, responsive và có tương tác.
  • Kết nối giao diện với dữ liệu qua API, kiểm thử và triển khai sản phẩm.
  • Bài giảng: khái niệm → minh họa → giảng viên demo → trao đổi → tổng kết.
  • Thực hành: giảng viên demo → bài tập có hướng dẫn → sinh viên thực hành → tổng kết.
  • Dự án tích hợp kiến thức qua các chương; bài giảng không yêu cầu từng sinh viên có laptop.

CHUẨN ĐẦU RA HỌC PHẦN

CLO1–CLO7

CLO1

Giải thích client–server, HTTP request–response và vai trò HTML/CSS/JavaScript/API/trình duyệt.

CLO2

Xây dựng HTML có ngữ nghĩa, form hợp lệ, SEO và khả năng tiếp cận cơ bản.

Hiện thực giao diện mobile-first bằng CSS, Flexbox, Grid và Bootstrap 5.

Xử lý dữ liệu, DOM, sự kiện, form và browser storage bằng JavaScript.

CLO5

Tích hợp REST API bằng Fetch API; xử lý các trạng thái đang tải, thành công, chưa có dữ liệu và lỗi.

CLO6

Dùng Git/GitHub và DevTools để quản lý phiên bản, cộng tác và gỡ lỗi.

CLO7

Làm việc nhóm để xây dựng, kiểm thử, triển khai và bảo vệ ứng dụng Frontend.
