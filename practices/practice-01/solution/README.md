# TH01 Sample — CSE122 News

Đây là phiên bản tham khảo hoàn chỉnh bằng HTML thuần. Không có CSS, JavaScript, framework, backend hoặc cơ sở dữ liệu.

## Chạy thử

Trong Terminal tại thư mục `solution`, chạy:

```text
python -m http.server 5500
```

Mở <http://localhost:5500>. Có thể mở trực tiếp `index.html` nếu máy chưa cài Python. Các hình minh họa SVG nằm trong `assets/` và được phân phối cùng project.

## Git

```text
git init
git status
git add index.html assets
git commit -m "Build CSE122 News homepage"
git log --oneline
```
