# TH01 Starter — CSE122 News

## Bắt đầu

1. Mở thư mục `starter` trong VS Code.
2. Mở `index.html`, tìm các ghi chú `TODO` và hoàn thiện từng phần.
3. Trong Terminal ở thư mục `starter`, chạy `python -m http.server 5500`.
4. Mở <http://localhost:5500> bằng Chrome. Nhấn F12 để mở DevTools.
5. Sau khi hoàn thành, mở Terminal tại thư mục `starter` để dùng Git.

Nếu chưa có Python, mở trực tiếp `index.html` bằng Chrome. Hãy dùng server để luyện quy trình chạy Web cục bộ.

## Git cơ bản

```text
git init
git status
git add index.html assets
git status
git commit -m "Build first news page"
git log --oneline
```

Chạy `git init` khi thư mục chưa phải repository. Việc đẩy mã nguồn lên GitHub là tùy chọn; không commit mật khẩu, token hoặc thông tin riêng tư.
